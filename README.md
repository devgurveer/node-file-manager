# Node File Manager

A simple command-line file manager built with Node.js using the File System and Readline modules.

## Features

- Create files
- Read files
- Append content
- Delete files
- List files
- Rename files

## How to Run

```bash
git clone <https://github.com/devgurveer/node-file-manager.git>
cd node-file-manager
node app.js
